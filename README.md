# 漢字学習アプリ

フラッシュカードとクイズで漢字を覚えるWebアプリです。

## 機能

- **フラッシュカード** — 漢字をタップして音読み・訓読み・用例を確認
- **クイズ** — 4択問題で読み方と意味を確認、スコア表示あり
- **単元選択** — 単元ごとに出題範囲を絞れる

## 収録単元

| Unit | タイトル | 教科書ページ |
|------|----------|-------------|
| 1 | アイスプラネット(1) | p.15〜20 |
| 2 | アイスプラネット(2) | p.21〜24 |
| 3 | 漢字に親しもう1(1) | p.25〜28 |
| 4 | 漢字に親しもう1(2) | p.28 |

## ローカル起動

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認。

## データ追加方法

`app/data/kanji.ts` の `kanjiData` 配列に追記するだけで漢字を追加できます。
